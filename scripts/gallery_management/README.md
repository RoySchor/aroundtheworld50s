# Gallery Management System

> **Simple terminal-based system for managing home page rotating gallery images**

This system provides a simple terminal script for managing the rotating gallery on your home page, following the same pattern as the blog management system.

## 🚀 Features

- **Web Interface Configuration** - Plan changes with visual preview
- **Terminal Script Execution** - Run Python script to apply changes
- **Interactive Approval** - Review changes before deployment
- **Automatic File Finding** - Searches common locations for image files
- **Complete Workflow** - File operations → Linting → Dev server → Approval → Deploy

## 🖥️ Usage

### 1. Web Interface (Configuration)
1. Navigate to `/admin` → Gallery Manager tab
2. Add/remove images with preview
3. Get terminal command to run

### 2. Terminal Script (Execution)
```bash
# List current images
python3 -m scripts.gallery_management.gallery_manager list

# Add images (provide full paths)
python3 -m scripts.gallery_management.gallery_manager add ~/Desktop/image1.jpg ~/Desktop/image2.png

# Remove images (provide filenames)
python3 -m scripts.gallery_management.gallery_manager remove IMG_1508.jpeg IMG_1628.jpeg

# Update with JSON (generated by web interface)
python3 -m scripts.gallery_management.gallery_manager update '{"add_images": ["new1.jpg"], "remove_images": ["old1.jpg"]}'
```

## 📋 Typical Workflow

1. **Prepare** - Save new images to Desktop/Downloads
2. **Configure** - Use web interface to plan changes
3. **Execute** - Copy and run generated terminal command
4. **Review** - Script opens dev server at http://localhost:3000
5. **Approve** - Interactive terminal prompt (y/n/r)
6. **Deploy** - Automatic git commit, push, and deployment

## 🔍 Auto File Finding

The script automatically searches:
- `~/Desktop/` - Desktop folder
- `~/Downloads/` - Downloads folder
- `~/Documents/` - Documents folder
- Current project directory

*If files aren't found, you'll be prompted for full paths.*

## 📁 File Details

**Gallery Location:** `src/assets/homePageGallery/`
**Supported Formats:** `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`
**Current Images:** 8 images (use `list` command to see them)

## 🔄 Interactive Deployment

When running `update` command:

1. **File Operations** - Copy new images, remove old ones
2. **Linting** - Run `npm run lint:fix`
3. **Dev Server** - Start http://localhost:3000 for review
4. **User Review** - Check rotating gallery on home page
5. **Approval Choice:**
   - `y/yes` - Approve and deploy to production
   - `n/no/r/revert` - Reject and revert all changes
6. **Deploy/Rollback** - Automatic based on your choice

## 🛡️ Safety Features

- **Automatic rollback** if deployment fails or rejected
- **File validation** for supported image formats
- **Naming conflict resolution** with automatic numbering
- **Process management** kills existing dev servers
- **Git integration** with proper commit messages
